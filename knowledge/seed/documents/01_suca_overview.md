# SUCA Overview

SUCA es un laboratorio de compresion visual y analisis tecnico.

El proyecto combina compresion de imagen, analisis perceptual, embeddings visuales, OCR visual heuristico, un mapa de pesos inspirado en criterios neuronales y un flujo local de RAG.

La meta principal no es solo reducir tamano. La meta es reducir tamano sin perder informacion visual importante para el tipo de imagen que se esta procesando.

SUCA distingue entre clases de contenido como foto, documento, interfaz, grafico y huella. Esa clasificacion cambia decisiones de formato, escala y calidad.

El sistema puede producir reportes tecnicos, dataset records e indices RAG para usar el conocimiento generado por las propias corridas del compresor.
