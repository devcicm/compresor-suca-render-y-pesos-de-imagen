# SUCA RAG And Embeddings

SUCA tiene dos ideas relacionadas con RAG.

La primera es el embedding visual artesanal. Ese embedding resume propiedades de grises, densidad, proyecciones, bordes, entropia y patrones tipo ridge. Sirve para comparar imagenes por similitud visual.

La segunda es el RAG semantico con LM Studio. En ese flujo, SUCA convierte resultados tecnicos a texto y genera embeddings semanticos para hacer consultas mas cercanas al lenguaje natural.

El indice local puede responder preguntas recuperando contexto previamente guardado. Si el contexto no es suficiente, la respuesta correcta debe decir que falta evidencia.

Una prueba de RAG no busca solo una frase exacta. Busca conservar la idea correcta aunque cambien palabras, longitud o estilo.
